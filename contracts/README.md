# Contracts

This directory contains the API contracts and schemas for the Multilingual AI-Powered Agricultural Assistant microservices.

- `query-api.yaml`: OpenAPI spec for the Query Service.
- `advisory-api.yaml`: OpenAPI spec for the Advisory Service.
- `context-item.schema.json`: JSON schema for retrieved documents/APIs. Note: Member C will later supply retrieved document chunks and external API context following this schema.
